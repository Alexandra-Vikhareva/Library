# 📚 Library Management System

Веб-приложение для управления личной библиотекой книг. Проект выполнен в рамках курса [The Odin Project](https://www.theodinproject.com/lessons/node-path-javascript-library).

## ✨ Возможности

- **📖 Добавление книг** - Ввод информации о книге (название, автор, страницы, статус прочтения)
- **👀 Просмотр коллекции** - Отображение всех книг в виде карточек
- **🔄 Изменение статуса** - Отметка книг как прочитанных/непрочитанных
- **🗑️ Удаление книг** - Удаление книг из коллекции
- **💾 Локальное хранилище** - Данные сохраняются между сессиями браузера
- **📱 Адаптивный дизайн** - Оптимальное отображение на разных устройствах
- **✅ Валидация форм** - Проверка корректности вводимых данных

## 🎯 Как использовать
- Добавление книги - Нажмите кнопку "Add New Book" и заполните форму
- Просмотр коллекции - Все книги отображаются на главной странице
- Изменение статуса - Нажмите на кнопку "Read/Unread" для изменения статуса
- Удаление книги - Используйте кнопку "Delete Card" для удаления книги

## 🛠 Технологии

- **HTML5** - Семантическая разметка, формы
- **CSS3** - Grid Layout, Flexbox, CSS переменные, анимации
- **JavaScript ES6+** - Классы, модули, DOM манипуляции
- **Local Storage API** - Сохранение данных в браузере
- **JSON** - Сериализация данных

## Компоненты интерфейса
- **Header** - Заголовок приложения
- **Book Grid** - Сетка с карточками книг
- **Add Book Button** - Кнопка открытия формы
- **Modal Form** - Всплывающее окно для добавления книг
- **Book Card** - Карточка отдельной книги

## 🎨 Дизайн и UX

### Цветовая схема
- **Основной цвет** - Нейтральный тона для чтения
- **Карточки книг** - Чистый белый фон с тенями
- **Статусы** - Зеленый для прочитанных, красный для непрочитанных
- **Кнопки** - Интуитивно понятные цвета действий

### Адаптивность
**Десктоп** - 4-5 карточек в ряд
**Планшет** - 2-3 карточки в ряд
**Мобильный** - 1 карточка в ряд

## 🐛 Известные ограничения
- Максимальный размер Local Storage: ~5MB
- Нет поддержки изображений обложек книг
- Отсутствует поиск и фильтрация
